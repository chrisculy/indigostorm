# Indigo Storm — Playtest Log

One entry per session. Fill in the summary table as you go so results are easy to compare with the simulator's predictions.

## Getting set up

1. Build the cards: `python3 make_print.py` (output in `print/`).
2. Print on US Letter, double-sided with **flip on long edge**. Every fronts page is followed by its backs page. Cut on the marks; penny sleeves with a playing card behind each make shuffling easier.
3. You'll also need **4 six-sided dice** (Timer Dice), **2 tokens** for the Lead and Exposure tracks, and the **Campaign Sheet** in a sheet protector with a dry-erase marker.
4. For Days 6, 11, 16, 21 and 26, start with that pack's **Jump-In Card**. Build the 12-card deck it lists (PROTO cards are in `Prototype Extras.pdf`), and check its perks on your sheet. Then set up normally. Read the Prototype Extras rules card once for how jump-ins and perks work.
